# Workflow Eval

## Oracle

- expected route: strict or compact worker Lane → exact commit Review → Lane metadata handoff commit → main Work Front Desk → one candidate → independent exact-range main Review
- architecture gate: only a new/changed ownership, shared contract, scope, or dependency boundary returns to Architect
- must ask: one actionable prerequisite for unsafe candidate isolation, unavailable commit/handoff evidence, conflict, or genuine user-owned intent/evidence
- must not ask: no main Architect Front Desk, post-Review commit assumption, all-dirty-equals-unmergeable shortcut, chat-summary authority, repeated unchanged Integration approval, or unattended all-Lane merge
- required artifacts: Golden lifecycle, Bootstrap, Action/Close/Main Desk contracts, Build/Review contracts, roles, Integration queue/control, README, release metadata
- acceptance criteria: all Golden cases agree; one pasted return line carries reconstruction locators/preferences; exact reviewed candidate is provable; source dirt and removal safety are separate; the next merge never stacks on dirty Integration tracking
- verification oracle: deterministic text, reference, fence, language, version, field, and hot-file-size assertions
